### 1. Claude Code 回覆：英文硬換行

⏺ NoMess runs quietly in the menu bar and watches what you copy
  from the terminal. When a long answer from a tool like Claude
  Code is broken into short lines by the window width, it joins
  those lines back into real paragraphs before you paste.

  Nothing is uploaded anywhere. Every rule runs locally, and
  copies from browsers, editors or password managers are never
  even read.


### 2. 中文與中英混排

  終端機會依照視窗寬度把長句子切斷，所以複製出來的文字常常變成一
  行一行的碎片。NoMess 會判斷哪些換行只是因為寬度不夠才出現的，
  把它們接回完整的段落；中文字之間不會多出空白，而中文和 English
  words 之間原本的空白也會保留下來。


### 3. 列表：每一項接回，但項目之間保持分開

  - Rejoins wrapped lines inside each bullet so every item reads
    as one complete sentence again
  - Keeps separate bullets separate, even when an item is long
    enough to wrap twice in a narrow window
  - Short items stay exactly as they were
